## Updating This List

When the user says "update AIMM members", "refresh store list", or similar:

1. Fetch `https://stores.localmusicshop.com/store-locator` and compare against this table
2. Navigate to `https://stores.localmusicshop.com/store/[id]` for any new store to confirm its website URL
3. Add new entries to the table
4. For stores no longer listed, add `status: inactive` to their Notes column — do not delete rows
5. Update the Last Updated date at the top of this file

---

## Search Order

The `#` column controls which stores are tried first when searching for a product image. Lower numbers are tried first. Current order is alphabetical — update numbers to reprioritize.

Ted Brown Music (#56) is excluded from searches by default per `registry/user-preferences.md`. Include it only when the user explicitly requests it.

---

## Per-Store Search Process

When searching a store for a product (brand + model + optional SKU):

1. Navigate to the store's website (from the Website column above)
2. Use the site's search with `[Brand] [Model]` as the query
3. If no results, try `[Model]` alone, then `[SKU]` if provided
4. If a product page is found, confirm the match — brand, model, and variant must all match
5. Extract the requested data (images, specs, etc.) per the calling skill's instructions
6. Return after the first store that yields usable results

If no store has the product: note how many stores were checked and flag as not found.

## AIMM Verification

A store is AIMM-affiliated if it appears on `https://stores.localmusicshop.com/store-locator`. No secondary verification is needed.

---

## Excluded Retailers (Never Use as AIMM Sources)

Even if they claim AIMM affiliation, do not use:

- Sweetwater
- Guitar Center
- Music & Arts
- Sam Ash
- Any national chain retailer not on the AIMM locator page

Exception: These retailers may be consulted for discontinued product verification only — not for any content we publish.
